# Project Guide: Build a Database-Backed REST API

## Goal
Create a small API for a clear use case, such as task tracking, library books, or campus events.

## Minimum milestones
1. Define entities and API endpoints.
2. Create the database schema and constraints.
3. Implement create, read, update, and delete operations.
4. Validate incoming data and handle missing/invalid records.
5. Add automated tests for normal and failure cases.
6. Document setup, environment variables, and sample requests.
7. Deploy the application or provide reproducible run instructions.

## Deliverables
- Source repository
- README and architecture overview
- Database schema
- Endpoint table with request/response examples
- Tests and test results
- Deployment instructions

## Verification questions
- Why did you choose these entities and relationships?
- What happens when an ID does not exist?
- How do you prevent invalid data?
- Which tests cover error cases?
- How are secrets kept out of source control?

## Related skills
Java, Spring Boot, REST, SQL, testing, Git, deployment.
