# Learning Path: Data Analytics

## Intended outcome
A learner can answer a practical question from raw data and present reproducible findings in a report or dashboard.

## Stage 1 — Spreadsheet and data literacy
Topics: tables, sorting/filtering, formulas, pivot tables, data types, duplicates, missing values.
Practice: clean a small dataset and summarize key metrics.
Exit evidence: documented cleaning decisions and a summary sheet.

## Stage 2 — SQL
Topics: SELECT, WHERE, ORDER BY, CASE, joins, aggregation, subqueries, CTEs, window functions as appropriate.
Practice: answer a set of business questions from a relational dataset.
Exit evidence: query file plus explanations and checked results.

## Stage 3 — Statistics and analytical reasoning
Topics: distributions, mean/median, variability, sampling, correlation, uncertainty, avoiding causal overclaims.
Practice: interpret trends and compare groups.
Exit evidence: written analysis that states assumptions and limitations.

## Stage 4 — Python and pandas
Topics: loading data, filtering, grouping, joining, reshaping, plotting.
Practice: convert manual analysis into a reproducible notebook or script.
Exit evidence: runnable analysis with clear steps.

## Stage 5 — Visualization
Topics: chart selection, labels, accessibility, metric definitions, dashboard layout.
Practice: build a dashboard around a specific stakeholder question.
Exit evidence: dashboard with meaningful KPIs and clear takeaways.

## Stage 6 — Communication and portfolio
Topics: executive summary, recommendations, limitations, reproducibility.
Practice: publish a case study describing question, data, method, findings, and next steps.
Exit evidence: portfolio-ready analysis and source files.

## Personalization rules
- If SQL is not demonstrated, prioritize Stage 2.
- If queries work but conclusions are weak, prioritize Stage 3 and Stage 6.
- If analysis is sound but hard to interpret, prioritize Stage 5.
- If work cannot be reproduced, prioritize Stage 4 and documentation.
