# Skill Criteria: Model Evaluation

## Evidence signals
- Uses an appropriate train/validation/test strategy
- Prevents leakage between training and evaluation
- Compares with a baseline
- Selects metrics that fit the task and class distribution
- Explains errors and trade-offs
- Documents limitations and reproducibility details

## Evidence levels
- Not yet verified: no evaluation artifacts found
- Partial: metric values appear without a clear methodology
- Supported: evaluation method and metrics are justified
- Strongly supported: baseline comparisons, error analysis, reproducible experiments, and thoughtful limitations

## Important note
A high score alone does not prove a model is valid. Check data leakage, metric choice, and test-set handling.
