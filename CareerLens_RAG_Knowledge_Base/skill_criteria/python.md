# Skill Criteria: Python

## Evidence signals
- Code uses functions and appropriate data structures
- Handles invalid or missing input where relevant
- Uses modules and dependencies clearly
- Includes meaningful names and basic documentation
- Has runnable examples or tests
- Repository setup instructions work

## Evidence levels
- Not yet verified: no accessible evidence was found
- Partial: snippets or a small exercise show some ability
- Supported: a runnable project demonstrates relevant use
- Strongly supported: multiple examples show maintainability, tests, and clear explanations

## Do not infer
A resume keyword, repository language badge, or generated code alone is not sufficient proof of independent skill. Record source limitations and ask the student to explain their work when useful.
