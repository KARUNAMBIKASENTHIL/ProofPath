# Skill Criteria: API Development

## Evidence signals
- Clear endpoints and HTTP methods
- Appropriate status codes and JSON responses
- Request validation and useful error messages
- Separation of routing, business logic, and data access where suitable
- Tests for successful and unsuccessful requests
- Documentation with example requests and responses

## Evidence levels
- Not yet verified: no accessible API evidence
- Partial: simple endpoint with little validation or documentation
- Supported: working API with validation and database or service integration
- Strongly supported: automated tests, consistent errors, secure configuration, and deployment evidence
