# Skill Criteria: SQL

## Evidence signals
- Uses filtering, sorting, joins, and aggregation correctly
- Models relationships with suitable keys and constraints
- Handles nulls and duplicates intentionally
- Understands transactions and basic data integrity
- Queries answer a defined question and results are checked
- Can explain query behavior and trade-offs

## Evidence levels
- Not yet verified: no accessible SQL evidence found
- Partial: isolated queries or exercises
- Supported: a database-backed project with schema and meaningful queries
- Strongly supported: well-tested queries, sound modeling, and clear performance/data-integrity reasoning

## Do not infer
Mentioning SQL on a resume is not evidence by itself. Missing database access should be reported as an evidence limitation.
